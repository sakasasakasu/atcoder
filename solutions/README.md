# solutions/

問題の「解法メモ」を置くディレクトリです。このディレクトリ直下の `.md` ファイルが 1 件 1 解法として解析され、「解法」タブに表示されます。

- `README.md`（このファイル）は解析対象外です。
- 同じ名前の `.cpp`（例: `ダイクストラ法.cpp`）を置くと、モーダルでコードを見られるようになります。

## 書き方

ファイル先頭の `# タイトル` は解法のタイトルとして扱われ、本文からは除外されます。

```markdown
# ダイクストラ法

単一始点最短路。`[[ABC471-A]]` で解いた。
```

## 言及（メンション）

`.md` 内で `[[対象ID]]` と書くと、その部分が自動でハイパーリンクになり、対象側にもタグが付きます（`.md` は編集されません）。

- 問題: `[[ABC471-A]]` や `[[典型-002]]`（コンテストID-問題ID）
- 解法: `[[ダイクストラ法]]`（ファイル名）

例:

```markdown
# しゃくとり法

[[ABC460-C]] で初めて使った。区間の伸縮がポイント。
```
