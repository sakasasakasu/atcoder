# solutions/

問題の「解法メモ」を置くディレクトリです。`solutions/` 直下の**グループ（ディレクトリ）**ごとに `.md` ファイルを置くと、「解法」タブにグループ別で表示されます。

```
solutions/
├── README.md          # このファイルは解析対象外
└── 典型テクニック/
    ├── ダイクストラ法.md
    └── ダイクストラ法.cpp   # （任意）コードがあるとモーダルで表示
```

- 各グループの `README.md` は解析対象外です。
- 同じ名前の `.cpp`（例: `ダイクストラ法.cpp`）を置くと、モーダルでコードを見られるようになります。

## 書き方

ファイル先頭の `# タイトル` は解法のタイトルとして扱われ、本文からは除外されます。

```markdown
# ダイクストラ法

単一始点最短路。`[[ABC471-A]]` で解いた。
```

本文では `$...$`（インライン）と、`$$` を独立行に置いたブロック数式が LaTeX として使えます。

```markdown
$C_L$ のようなインラインと、
$$
C_L = \min_{i} C_i
$$
のようなブロック。
```

## 言及（メンション）

`.md` 内で `[[対象ID]]` と書くと、その部分が自動でハイパーリンクになり、対象側にもタグが付きます（`.md` は編集されません）。

- 問題: `[[ABC471-A]]` や `[[典型-002]]`（コンテストID-問題ID）
- 解法: `[[ダイクストラ法]]`（ファイル名。グループをまたいで一意にする）

例:

```markdown
# しゃくとり法

[[ABC460-C]] で初めて使った。区間の伸縮がポイント。
```
