# tips/

短い Tips（小ネタ・コツ）を置くディレクトリです。`tips/` 直下の**グループ（ディレクトリ）**ごとに `.md` ファイルを置くと、「Tips」タブにグループ別のタイル一覧で表示されます。

```
tips/
├── README.md          # このファイルは解析対象外
└── 典型テクニック/
    └── 二分探索の終了条件.md
```

- 各グループの `README.md` は解析対象外です。
- ファイル先頭の `# タイトル` は Tips のタイトルとして扱われ、本文からは除外されます。
- 本文では `$...$`（インライン）と、`$$` を独立行に置いたブロック数式が LaTeX として使えます。

```markdown
# 二分探索の終了条件

半開区間 $[l, r)$ を考えると終了条件が扱いやすい。
```
