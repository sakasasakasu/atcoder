# problems/

解いた問題を置くディレクトリです。`problems/` 直下の各ディレクトリが「セクション」として問題一覧に表示されます。

## 構成

### コンテスト形式（サブディレクトリ = 1 コンテスト）

セクション内にサブディレクトリがある場合、各サブディレクトリが 1 コンテストとして扱われます。

```
problems/
└── ABC/
    └── ABC471/
        ├── README.md   # 感想 + `## A問題`〜`## G問題` のようなセクション
        ├── A.cpp       # A問題の解答コード
        ├── A1.cpp      # （任意）A問題の別解コード
        └── B.cpp
```

- `README.md` の `## X問題`（A〜G）が問題カードになります。
- コードは「問題ID で始まる `.cpp`」（`A.cpp` / `A1.cpp` …）をすべて拾います。
- コンテスト名は降順（新しい順）で表示されます。

### 典型形式（直下の .cpp = 1 問題）

セクション内にサブディレクトリがなく、`.cpp` が直接置かれている場合、1 ファイル = 1 問題として扱われます。

```
problems/
└── 典型/
    ├── 002.cpp
    └── 004.cpp
```

- `main.cpp`（ローカル作業用）は除外されます。
- ファイル名は数値昇順で表示されます。

### どちらでもない場合

- 空のセクションや `README.md` だけのセクションは表示されません。

## 新しい問題を追加する

ABC コンテストは CLI で生成できます（リポジトリ直下で実行）。

```bash
./new-abc ABC471 --cpp --problems ABCD
```

その他のセクション（`ARC/` など）は `problems/<セクション名>/` にディレクトリとファイルを追加するだけで自動的に拾われます。
