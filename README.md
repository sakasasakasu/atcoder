## 新しい問題を追加する

`problems/ABC/ABC###/`（例: `ABC471`）の新規問題ディレクトリは、手作業でファイルを作らずに CLI で生成できます。

`portfolio/` ディレクトリで実行します。

```bash
# 基本（README.md を生成）
npm run new:abc -- ABC471

# 数字のみでも可
npm run new:abc -- 471

# 生成内容のプレビュー（ファイルは作成しない）
npm run new:abc -- 471 --dry-run

# 問題セクションを指定（例: A, B, C のみ）
npm run new:abc -- 471 --problems ABC

# 感想を入れて生成
npm run new:abc -- 471 --summary "今回は2完"

# 解答コードの雛形も生成（デフォルトでは生成しない）
npm run new:abc -- 471 --cpp

# 俺が本当に使うもの
npm run new:abc -- 471 --cpp --problems ABCD
```

### 生成されるファイル

```
problems/ABC/ABC471/
├── README.md        # 問題一覧の元データ。`## A問題` のようなセクションを含む
├── A.cpp            # A問題の解答コード
├── A1.cpp           # （任意）A問題の別解コード
└── B.cpp            # B問題の解答コード
```

`--cpp` を指定した場合は、`--problems` で指定した範囲の `X.cpp` の雛形も生成されます。

## 解法（solutions/）

問題の解き方のメモは `solutions/` ディレクトリに置きます。

```
solutions/
├── README.md         # このファイルは解析対象外
├── ダイクストラ法.md  # 1 ファイル = 1 解法
└── ダイクストラ法.cpp # （任意）実装コード
```

ファイル先頭の `# タイトル` は解法のタイトルとして扱われます。

## 言及（メンション）で問題と解法をリンクする

`.md` 内で `[[対象ID]]` と書くと、生成時に自動でハイパーリンクになり、対象側にタグ（バックリンク）も付きます。`.md` 自体は編集されません。

- 問題 ID: `[[ABC471-A]]` / `[[典型-002]]`（コンテストID-問題ID）
- 解法 ID: `[[ダイクストラ法]]`（solutions のファイル名）

例（解法のメモ内）:

```markdown
# ダイクストラ法

[[ABC471-A]] で初めて使った。
```

- 解法内の `ABC471 A問題` の部分が問題カードへのリンクになり、問題カード側に「解法: ダイクストラ法」タグが付きます。
- 逆に問題の `README.md` 内で `[[ダイクストラ法]]` と書けば、解法カード側にタグが付きます。

## 新しい解法・ライブラリを追加する

`solutions/` に `.md` を、`library/` にカテゴリディレクトリと `.md` を置くだけです。表示には JSON の再生成が必要です。

### オプション

| オプション | 内容 |
|---|---|
| `-p, --problems <文字列>` | 生成する問題セクション（デフォルト: `A-G`）。`A-C` は A,B,C / `A,C` は A,C / `ABC` は A,B,C / `A-G` は A〜G。重複は除去し、A〜G 以外はエラー |
| `-s, --summary <テキスト>` | README の感想欄の初期テキスト |
| `--cpp` | `X.cpp` の雛形も生成 |
| `-d, --dry-run` | ファイルを作成せず、生成予定の内容を表示 |
| `-h, --help` | ヘルプを表示 |

### 注意

- コンテスト ID は `ABC###` または `###`（3桁）の形式のみ受け付けます。実在確認は行いません。
- 既に同じディレクトリ・ファイルが存在する場合はエラーになり、上書きはしません。
- 生成コマンドは Git 操作（add / commit / push）を実行しません。
- 生成後は `npm run dev`（または `npm run build`）を実行すると、`predev` / `prebuild` で `problems/` が JSON 化され、問題一覧に反映されます。
