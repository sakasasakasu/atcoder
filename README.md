# AtCoder 精進ポータル

AtCoder での競技プログラミング精進の記録を、管理し、静的サイトとして自動公開しています。

> https://sakasasakasu.github.io/atcoder/

```bash
# 基本（README.md を生成）
./new-abc 471

# 生成内容のプレビュー（ファイルは作成しない）
./new-abc 471 --dry-run

# 解答コードの雛形も A〜D まで生成（よく使う組み合わせ）
./new-abc 471 --cpp --problems ABCD

# 感想を入れて生成
./new-abc 471 --summary "今回は2完"
```
